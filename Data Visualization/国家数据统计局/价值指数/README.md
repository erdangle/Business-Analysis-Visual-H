# 价值指数 · 季度数据 BI 大屏（Swiss Typographic 瑞士国际主义风）

基于国家统计局「数据库 — 季度数据」构建的价值指数主题交互式数据大屏。生成器仅使用
**Python 标准库**（零第三方依赖），一条命令即可从 5 张原始 CSV 生成**单文件、离线可打开**的
瑞士国际主义风大屏 HTML。

> 视觉风格：Swiss Typographic —— 白底黑字、红色强调、发丝分隔线、左对齐粗标题、
> 几乎零装饰。风格选型依据见 `../风格库/README.md`（遵守用户偏好：不含图签/制表元素）。
> 另有 Jupyter Notebook 逐表可视化分析：`价值指数数据可视化.ipynb`。

## 数据内容（5 张表，两段时期）

| 数据表 | 时间范围 | 说明 |
| --- | --- | --- |
| 农产品生产者价格指数（上年同期=100） | 2025Q2—2026Q3 当季 | 总指数 + 17 个分类，部分品类存在季度缺报 |
| 固定资产投资价格指数_当季（-2018 旧口径） | 2017Q4—2018Q4 | 14 个分项 |
| 固定资产投资价格指数_当季（2019- 新口径） | 2019Q1—Q4 | 15 个分项（口径调整） |
| 固定资产投资价格指数_累计值（-2018 旧口径） | 2017Q4—2018Q4 | 14 个分项 |
| 固定资产投资价格指数_累计（2019- 新口径） | 2019Q2—Q4 | 15 个分项 |

## 大屏功能

- **5 张 KPI**：农产品价格总指数、上涨最高/下跌最深品类（自动识别）、固投价格总指数（当季/累计）
- **六张图表**：农产品总指数柱状（100 基准线）· 分类涨跌发散条形 · 主要品类多线走势 ·
  固投总指数历史走势（新旧口径拼接 + 口径切换标注区）· 固投分类涨跌发散 · 固投累计面积图
- **交互**：时间轴联动农产品三张图、播放轮播、点击柱线切换季度、详情钉住

## 快速开始

```bash
cd 价值指数
python generate_bi_dashboard.py             # 生成大屏并自动打开浏览器
python generate_bi_dashboard.py --no-open   # 只生成文件
```

生成结果：`价值指数BI大屏.html`（约 1MB，ECharts 已内联，双击即可离线打开）。

## 数据说明与口径

- 所有指数均为**同比指数（上年同期 = 100）**，涨跌幅度 = 指数 − 100。
- **缺报处理**：棉花、糖料、烟叶等品类存在季度缺报，解析器按季度轴对齐补空值
  （折线自动断点、排行自动隐藏），不做任何插补。
- **固投指数拼接**：该统计调查制度 2020 年起取消，数据止于 2019Q4；2018 年及以前与
  2019 年分类口径不同（如钢材/水泥 → 金属材料/非金属材料），总指数序列为两套口径拼接，
  分类别涨跌仅在同一口径内比较。
