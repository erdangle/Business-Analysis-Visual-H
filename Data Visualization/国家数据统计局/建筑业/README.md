# 建筑业 · 季度数据 BI 大屏（工程蓝图风 Blueprint）

基于国家统计局「数据库 — 季度数据」（2022Q2 — 2026Q3，共 18 个季度，累计值口径）构建的
建筑业主题交互式数据大屏。生成器仅使用 **Python 标准库**（零第三方依赖），一条命令即可从
10 张原始 CSV 生成**单文件、离线可打开**的工程蓝图风大屏 HTML。

> 视觉风格：工程蓝图（Blueprint / Tactical HUD）—— 深蓝图纸底、白色制图网格、
> 线框卡片 + 十字准星角标 + 等宽数字。风格选型依据见 `../风格库/README.md`。

## 大屏功能

- **6 张 KPI 卡**：建筑业总产值、签订合同总额、本年新签合同、房屋施工面积、企业单位数、从业人员（含累计同比）
- **智能速读**：按所选季度自动生成文字结论（总产值同比、新签占比、竣工产值率、在外省产值占比、新开工占比）
- **六张联动图表**：
  01 总产值构成堆叠（建筑工程/安装/装饰装修/其他）+ 累计同比线 ·
  02 签订合同结构（新签/结转）+ 同比线 ·
  03 施工/新开工/竣工面积三线 ·
  04 竣工面积分类排行（8 类）·
  05 竣工房屋价值分类排行（7 类）·
  06 企业财务快照（资产/负债/流动资产/应收工程款/存货）
- **交互**：时间轴拖拽、播放自动轮播、点击图 01—03 的柱线全局联动、点击数据点钉住详情

## 快速开始

```bash
cd 建筑业
python generate_bi_dashboard.py             # 生成大屏并自动打开浏览器
python generate_bi_dashboard.py --no-open   # 只生成文件
```

生成结果：`建筑业BI大屏.html`（约 1MB，ECharts 已内联，双击即可离线打开）。
首次运行自动下载 ECharts 并缓存为 `echarts.min.js`（已加入 .gitignore）。

## 数据说明与已知口径

- **内容指纹识别**：下载的两张表文件名与内容互换了（"企业总收入.csv"内是竣工房屋价值分类、
  "房屋建筑竣工价值.csv"内是企业总收入）。生成器按表格内指标行自动识别类型，无需改名。
- **重复表**："费用情况"表与"利润"表内容完全相同，自动去重（先到先得）。
- **时序表（6 张）**：18 个季度，累计值口径；同比为累计口径（与上年同期累计值相比）。
- **竣工房屋价值表**：缺 2026Q1（共 17 期），按季度键映射，缺失季度排行图自动隐藏；
  "厂房竣工价值"仅 1 期有值，未纳入。
- **财务快照（4 张中的 3 张）**：企业财务指标统计制度无四季度数据，最近一期为 2017Q1，
  以快照卡呈现（资产负债率、产值利润率、应收工程款占流动资产比、主营业务成本率），
  仅作结构参考，不参与时序联动。

## 数据来源与口径

- 数据来源：国家统计局「数据库 — 季度数据」（https://data.stats.gov.cn）
- 面积单位：万平方米；金额单位：亿元；同比为累计口径
- 房屋建筑分类按 2021 年统计年报制度修订（商厦、宾馆等类别不再统计）
