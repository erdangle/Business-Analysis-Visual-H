# 文化产业 · 季度数据 BI 大屏

本文件夹含**两款风格的大屏**（数据与交互一致，任选使用）：

| 版本 | 风格 | 生成器 | 输出 |
| --- | --- | --- | --- |
| 第一版 | Aurora 极光渐变（深色） | generate_bi_dashboard.py | 文化BI大屏.html |
| 第二版 | Bento Grid 便当格（浅色） | generate_bi_dashboard_bento.py | 文化BI大屏-便当格.html |

基于国家统计局「数据库 — 季度数据」（规模以上文化及相关产业，2025Q2 — 2026Q2 共 5 期）
构建的文化产业主题交互式数据大屏。生成器仅使用 **Python 标准库**（零第三方依赖），
一条命令即可从 6 张原始 CSV 生成**单文件、离线可打开**的极光渐变风大屏 HTML。

> 视觉风格：Aurora UI —— 深底青紫粉极光光晕、半透明毛玻璃卡片、渐变标题与柔和发光。
> 风格选型依据见 `../风格库/README.md`（遵守用户偏好：不含图签/制表信息元素）。

## 大屏功能

- **6 张 KPI 卡**：营业收入、利润总额、资产总计（季末）、核心领域占比、文化服务业占比、增长最快大类（含最慢）
- **智能速读**：按所选季度自动生成文字结论（营收与利润同比、核心领域与服务业占比、增长最快/最慢大类）
- **六张联动图表**：
  01 营业收入走势（累计柱 + 累计增长线）·
  02 九大产业结构排行（含增速标注）·
  03 九大类累计增长对比（正负分色）·
  04 增长 × 占比象限（气泡 = 营收规模，文化版"波士顿矩阵"）·
  05 三大行业构成 100% 堆叠（文化制造 / 批发零售 / 文化服务业）·
  06 利润与资产双轴（利润累计柱 + 资产季末线）
- **交互**：时间轴拖拽、播放自动轮播、点击图 01/06 的柱线全局联动、点击数据点钉住详情

## 快速开始

```bash
cd 文化
python generate_bi_dashboard.py             # 生成大屏并自动打开浏览器
python generate_bi_dashboard.py --no-open   # 只生成文件
```

生成结果：`文化BI大屏.html`（约 1MB，ECharts 已内联，双击即可离线打开）。
首次运行自动下载 ECharts 并缓存为 `echarts.min.js`（已加入 .gitignore）。

## 数据说明与口径

- 时间范围：2025Q2 — 2026Q2 共 5 期；**营业收入、利润为累计值口径，资产总计为季末存量口径**；
  "累计增长 / 同比"均由统计局直接发布，非本屏计算。
- 九大类（新闻信息服务 / 内容创作生产 / 创意设计服务 / 文化传播渠道 / 文化投资运营 /
  文化娱乐休闲 / 文化辅助生产和中介服务 / 文化装备生产 / 文化消费终端）依据
  《文化及相关产业分类（2018）》；生成器内置"九大类合计 ≈ 总营收"对账校验。
- 核心领域 / 相关领域、文化制造 / 批发零售 / 服务业占比为统计局发布的官方比重。
