# 国民经济核算 · 季度数据 BI 大屏（深色科技版）

基于国家统计局「数据库 — 季度数据」（2022Q2 — 2026Q3，共 18 个季度）构建的交互式数据大屏。
生成器仅使用 **Python 标准库**（零第三方依赖），一条命令即可从 6 张原始 CSV 生成
**单文件、离线可打开** 的深色科技风大屏 HTML。

## 大屏功能

- **6 张 KPI 卡**：GDP 规模、第三产业占比、最终消费 / 资本形成 / 净出口贡献率（带同比与环比变动、增减着色）
- **智能速读**：按所选季度自动生成一段文字结论（含增长最快 / 最弱的行业）
- **三栏布局 · 7 张联动图表**：
  GDP 规模与同比、环比增长动能、三次产业结构（堆叠 + 占比线）、三次产业同比增速、
  三次产业贡献率（100% 堆叠）、三大需求贡献率走势、12 个行业增速排行
- **交互**：当季值 / 累计值双口径切换、时间轴拖拽、播放自动轮播、
  点击任意图表的柱 / 线即可全局联动，选中季度悬浮卡停靠展示

## 快速开始

```bash
cd 国民经济核算
python generate_bi_dashboard.py             # 生成大屏并自动打开浏览器
python generate_bi_dashboard.py --no-open   # 只生成文件
```

生成结果：`国民经济核算BI大屏.html`（约 1MB，ECharts 已内联，双击即可离线打开）。

首次运行会自动从国内镜像下载 ECharts 并缓存到项目根目录的 `echarts.min.js`，此后完全离线可用；
若所有下载源均失败，页面会退化为联网加载 CDN。

## 数据说明

六张表均来自国家统计局「数据库 — 季度数据」（按当季 / 累计两种口径）：

| 数据表 | 大屏用途 |
| --- | --- |
| 国内生产总值（现价） | KPI、GDP 规模柱、三次产业结构堆叠、行业规模 |
| 国内生产总值（不变价） | 悬浮卡中的补充口径 |
| 国内生产总值指数（上年同期=100） | 同比增速（指数 − 100）、三次产业同比、行业增速排行 |
| 国内生产总值环比增长速度 | 环比增长动能、速读中的环比 |
| 三大需求对 GDP 增长的贡献率 | 消费 / 资本形成 / 净出口 KPI 卡与贡献率走势图 |
| 三次产业贡献率 | 贡献率 100% 堆叠图、第三产业占比卡 |

生成器内置数据校验：季度一致性、指标完整性、缺失值检查，并抽样核对 2025Q3 关键数值，
校验不通过会直接报错退出而不是生成错误的大屏。

## 数据来源与口径

- 数据来源：国家统计局「数据库 — 季度数据」（https://data.stats.gov.cn）
- 同比增速 = 指数 − 100（不变价口径）；第三产业占比按现价计算
- 贡献率之和因四舍五入可能不完全等于 100%
