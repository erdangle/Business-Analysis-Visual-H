# 人民生活 · 季度数据 BI 大屏（Glassmorphism 玻璃拟态风）

基于国家统计局「数据库 — 季度数据」（2025Q2 — 2026Q3 共 6 个季度）构建的人民生活主题
交互式数据大屏。生成器仅使用 **Python 标准库**（零第三方依赖），一条命令即可从 7 张原始 CSV
生成**单文件、离线可打开**的玻璃拟态风大屏 HTML。

> 视觉风格：Glassmorphism —— 浅色暖渐变底、磨砂半透明卡片（backdrop-blur）、
> 白描边 + 柔和投影。风格选型依据见 `../风格库/README.md`（遵守用户偏好：不含图签/制表元素）。
> 另有 Jupyter Notebook 逐表可视化分析：`人民生活数据可视化.ipynb`。

## 大屏功能

- **口径切换**：全国 / 城镇 / 农村 三口径一键切换，联动 6 张 KPI 卡与图 01—04
- **6 张 KPI 卡**：人均可支配收入、收入中位数、人均消费支出、恩格尔系数（中心环形图联动）、
  增长最快收入来源、增长最快支出大类
- **智能速读**：按所选口径与季度自动生成文字结论（收入/支出增速、恩格尔系数、城乡收入比）
- **八张联动图表**：
  01 收入走势（柱 + 增长线）· 02 四项收入构成堆积 · 03 八大类支出堆积 ·
  04 支出占比环形 · 05 城乡收入三线对比 + 城乡收入比 · 06 城乡八大类雷达 ·
  07 外出务工双轴（单季度）· 08 恩格尔系数与消费增速
- **交互**：时间轴拖拽、播放自动轮播、点击图 01/03 的柱线联动季度、点击数据点钉住详情

## 快速开始

```bash
cd 人民生活
python generate_bi_dashboard.py             # 生成大屏并自动打开浏览器
python generate_bi_dashboard.py --no-open   # 只生成文件
```

生成结果：`人民生活BI大屏.html`（约 1MB，ECharts 已内联，双击即可离线打开）。
首次运行自动下载 ECharts 并缓存为 `echarts.min.js`（已加入 .gitignore）。

## 数据说明与口径

- 时间范围：2025Q2 — 2026Q3 共 6 个季度；**收入与消费支出为人均累计值口径**，
  "累计增长"由统计局发布（人均可支配收入增速为扣除价格因素的**实际增速**，其余为名义增速）。
- 恩格尔系数 = 食品烟酒支出 ÷ 消费支出；城乡收入比 = 城镇 ÷ 农村（本屏计算）。
- 外出务工为**单季度**数据（非累计），2025Q4 单季数据统计局未发布，图表横轴不连续属正常。
- 八大类支出：食品烟酒、衣着、居住、生活用品及服务、交通通信、教育文化娱乐、医疗保健、
  其他用品及服务；四项收入：工资性、经营净、财产净、转移净收入。
